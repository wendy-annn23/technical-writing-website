TECHNICAL WRITING WEBSITE

PROJECT FILES
- index.html: Home / landing page
- lectures.html: Table of contents for seven lessons
- about.html: Student author information
- contact.html: Contact information and demonstration form
- technical-writing.html: Definition and purpose of technical writing
- abcs-technical-writing.html: ABCs of technical writing
- outlining-subject.html: Outlining the subject
- types-technical-paper.html: Types of technical paper
- basic-english-structure.html: Basic English structure
- parts-of-a-letter.html: Parts of a formal letter
- graphs-charts.html: Graphs and charts
- style.css: Shared baby-pink, black, and white styling
- script.js: Mobile navigation and contact-form validation
- images/logo.png: Website logo

TEST LOCALLY
1. Extract the TechnicalWriting folder.
2. Open index.html in a modern browser, or open the folder in Visual Studio Code and use Live Server.
3. Click every navigation item and lecture card to check the pages.

CONTACT FORM NOTE
The form is a front-end demonstration. It validates the required fields and email format, then prepares a mailto message only after you replace your-email@example.com in contact.html with the real recipient address. The website does not store messages or send them through a server.

PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository (for example, TechnicalWriting).
2. Upload the contents of this folder so index.html is in the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, select Deploy from a branch, choose the main branch and / (root), then save.
5. Wait for GitHub Pages to publish the site and open the provided URL.

All pages use relative links and the project uses only HTML, CSS, and vanilla JavaScript.
